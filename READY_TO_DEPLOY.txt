┌─────────────────────────────────────────────────────────────────────────────┐
│ ✅ WHAT HAPPENS AFTER DEPLOY                                                │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Vercel builds Python serverless function
     └─ Installs dependencies from requirements.txt
     └─ Creates immutable function

  2. First request triggers cold start
     └─ WSGI detects VERCEL environment variable
     └─ Runs: python manage.py migrate --noinput
     └─ Creates superuser if doesn't exist
     └─ App starts serving requests

  3. Subsequent requests are fast
     └─ No migrations (already applied)
     └─ Normal Django request handling

│ ⚠️ IMPORTANT: Why Build Scripts Don't Work                                 │
└─────────────────────────────────────────────────────────────────────────────┘

  ❌ Build happens BEFORE deployment
  ❌ No database access at build time
  ❌ Different environment (uv vs pip conflicts)
  ❌ Serverless = immutable functions

  ✅ WSGI runs at RUNTIME
  ✅ Database accessible
  ✅ Correct environment
  ✅ Runs before serving requests

  Read: WHY_WSGI_ONLY.md for full explanation
