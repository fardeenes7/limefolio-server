┌─────────────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK DEPLOY                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Setup database (Neon/Supabase/Vercel Postgres)
  2. Setup storage (Cloudflare R2/AWS S3)
  3. Run: vercel login
  4. Run: vercel --prod
  5. Set environment variables in Vercel Dashboard
  6. Run: vercel --prod (again)

┌─────────────────────────────────────────────────────────────────────────────┐
│ 📋 REQUIRED ENVIRONMENT VARIABLES                                           │
└─────────────────────────────────────────────────────────────────────────────┘

  SECRET_KEY=<generate-new-key>
  DEBUG=False
  ALLOWED_HOSTS=.vercel.app,yourdomain.com
  DATABASE_URL=postgresql://user:pass@host:port/db
  CORS_ALLOWED_ORIGINS=https://yourdomain.com
  
  AWS_ACCESS_KEY_ID=<your-key>
  AWS_SECRET_ACCESS_KEY=<your-secret>
  AWS_STORAGE_BUCKET_NAME=<bucket-name>
  AWS_S3_ENDPOINT_URL=<endpoint>
  AWS_S3_CUSTOM_DOMAIN=<domain>

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔧 ESSENTIAL COMMANDS                                                       │
└─────────────────────────────────────────────────────────────────────────────┘

  # Test before deploy
  ./test_deployment.sh
  python3 manage.py check_deployment
  
  # Deploy
  vercel --prod
  
  # View logs
  vercel logs --follow
  
  # Migrations
  python3 manage.py makemigrations
  python3 manage.py migrate
  python3 manage.py showmigrations
  
  # Environment
  vercel env pull
  vercel env add VARIABLE_NAME

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

  Migrations not running?
    → Check: vercel logs
    → Verify: DATABASE_URL in Vercel env vars
  
  Static files 404?
    → Check: build logs for collectstatic
    → Verify: STATIC_ROOT in settings.py
  
  Database connection error?
    → Verify: DATABASE_URL format
    → Check: Database allows Vercel IPs
  
  CORS errors?
    → Update: CORS_ALLOWED_ORIGINS
    → Include: Both www and non-www domains
